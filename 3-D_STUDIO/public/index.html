How to build a game

1 · Put things in the world

Press the big + under the 3D view to add shapes, or open the 🧩 Model Workshop to download real models (they show up with animations you can play).

Click an object in the 3D view to select it. Drag the arrows to move it. Keys: W move · E rotate · R scale · F focus · Del delete · ⌘D duplicate.

2 · Give it code

Every object has its own scripts, exactly like sprites in Scratch. Drag blocks from the categories on the left. Scripts start with a hat block: when ▶ clicked, when key pressed, when this touches…

3 · Press ▶

Physics turns on, scripts run. Press ■ and everything snaps back to where you put it.
