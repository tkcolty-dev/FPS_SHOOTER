How to build a game

1 · Put things in the world

Press the big + under the 3D view to add shapes, or open the 🧩 Model Workshop to download real models — they arrive with animations you can play.

Click an object in the 3D view to select it, then drag the arrows to move it. W move · E turn · R size · F focus · Del delete · ⌘D duplicate.

2 · Give it code

Every object has its own scripts, just like sprites in Scratch. Drag blocks from the categories on the left. Scripts start with a hat block: when ▶ clicked when key pressed when this touches…

3 · Press ▶

Physics switches on and the scripts run. Press ■ and everything snaps back to where you left it.

Your work is saved in this browser automatically. File → Save keeps a named copy; Export makes a single .html you can send to friends.
