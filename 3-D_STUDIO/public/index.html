How to build a game

1 · Put things in the world

Press the big + under the 3D view to add shapes, or open the 🧩 Model Workshop to download real models — they arrive with animations you can play.

Click an object to select it and just drag it across the ground (hold ⇧ to lift it). Right-click for a menu. W move · E turn · R size · G snap · F focus · ⌘Z undo · ⌘D duplicate · Del delete.

Fly around: hold the right mouse button to look, and use W A S D (Q/E down/up, ⇧ fast) while holding it.

Smart objects

The + menu also has ready-made objects with code inside: a drivable Player, Coin, chasing Enemy, Moving platform, Spawner, Goal, Button, Lamp, Sign. Add them, press ▶, then open their code to see how they work.

Terrain maker

Add Terrain from the + menu (World). The Sculpt tool turns on: drag on the ground to raise it, hold ⇧ to dig, use Smooth / Flatten to tidy up, and Paint to color paths, sand, snow or lava. Objects fall, roll and walk on it for real. 🎲 New hills rerolls the shape.

UI maker

The UI tab adds labels, buttons, bars, panels and images on top of the game. Drag them around on the 3D view, then use UI blocks: when UI button clicked set UI text to set UI bar to %

2 · Give it code

Every object has its own scripts, just like sprites in Scratch. Drag blocks from the categories on the left. Scripts start with a hat block: when ▶ clicked when key pressed when this touches…

3 · Press ▶

Physics switches on and the scripts run. Press ■ and everything snaps back to where you left it.

Your work is saved in this browser automatically. File → Save keeps a named copy; Export makes a single .html you can send to friends.
