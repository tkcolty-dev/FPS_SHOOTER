⚡ The Claude Bridge — live, like Roblox Studio

Keep this editor open. Tell Claude what you want and it builds it right here, live — sprites, costumes and block scripts appear instantly. Then you refine everything by hand. Claude also sees your live edits, so the next request builds on what you changed.

  1. Start the bridge: node bridge/server.js, then open http://localhost:4321.
  2. The badge top-right turns ● live when connected.
  3. Say to Claude: "add an enemy that chases the player and a score" — it appears in seconds.
  4. Drag blocks, add sprites & costumes. Hit ▶ to play. Ask Claude for the next change.
