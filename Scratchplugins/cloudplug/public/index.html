How to use

  1. Browser plugin (the main way): download the plugin, unzip it, open chrome://extensions, turn on Developer mode, Load unpacked → pick the folder. Open any project on scratch.mit.edu: a blue CloudPlug category appears in the palette and the blocks work while the project runs (editor and project page). Players of your game need the plugin too.
  2. No plugin? Template instead: download the template, File → Load it, build your game inside it, share it, add its project ID on the left and turn the bridge on (needs the Scratch login above). Works for everyone who plays, using only cloud variables: set [plug request] to (save&highscore&100) → broadcast [cloud plug] and wait → answer in plug response.
  3. Existing project without the plugin: make 10 cloud variables named ☁ TO_HOST, ☁ FROM_HOST_1 … ☁ FROM_HOST_9 (for all sprites), then Upload Sprite → CloudPlug.sprite3.
  4. TurboWarp: Custom Extension → URL above for the same blocks, or open a project with ?cloud_host= … so this server is its cloud.
