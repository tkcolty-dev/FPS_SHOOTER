Shortcuts

N
Note mode on / off. Click anything to note it, drag to note an area.
Right-click
Note the thing under the cursor, any time, without leaving the game.
Double-click
Open a thing in the Inspector while playing.
K
Sketch mode: draw boxes, arrows and labels over the game to show Claude what you want where.
F8
Pause / play.
.
Step one frame while paused.
B R M
Hitboxes · restart · sound. Hold Alt if the game uses those keys.
\
Hide or show the side panel.
Esc
Close this, cancel a note, leave note mode.
